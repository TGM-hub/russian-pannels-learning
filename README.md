# Cyrillic Reader

🔗 [Ouvrir l'appli](https://tgm-hub.github.io/russian-pannels-learning/)

Entraînement GeoGuessr : lire un panneau en cyrillique, l'écrire en latin, puis placer la ville sur la carte.

- 229 villes : Russie (101) + Ukraine, Biélorussie, Bulgarie, Serbie, Bosnie (RS), Monténégro, Macédoine du Nord, Kazakhstan, Kirghizistan, Mongolie
- Saisie tolérante (Kharkiv / Harkiv / Charkiw…), correction lettre par lettre
- Audio : RHVoice (voix natives ukrainienne, kirghize, macédonienne ; russe sinon). `Ctrl+Espace` pour réécouter.
- Carte : Natural Earth (régions administratives), sans étiquettes

## Options
- **Villes** ou **Régions RU** ; **Russie**, **Autres pays** ou **Tout**.
- **Couverture GeoGuessr** : seulement les villes couvertes ; **Sans clic carte** : lecture seule ; **Repères** : villes repères affichées.
- **Alphabet** : table de lecture par langue.
